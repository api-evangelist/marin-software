# Marin Software

> Marin Software is a performance marketing and digital advertising management platform used by e-commerce brands, agencies, and enterprise marketers to plan, automate, and optimize paid media across paid search, paid social, retail media, and app advertising. Marin Software has been acquired by Zax Capital. Marin publishes a narrow, POST-only REST write API over its bulk-upload engine and a second Social API whose reference is no longer reachable. There is no OpenAPI, no SDK, no MCP server, and no developer portal.

## APIs

- [Marin API](https://support.marinsoftware.com/en_US/bulk-actions/marin-api): POST-only REST API for programmatically writing campaigns, groups, keywords, ads and strategies into Marin. Base URL https://api.marinsoftware.com/open-api, version 0.1, HTTPS only, HTTP Basic auth with a Marin username and password.
- [APIs overview](https://support.marinsoftware.com/en_US/Managing_Campaigns/api): Marin offers two APIs — the Social API for Meta statistics, advertisers and Media Plan creation, and the Marin API for all other publishers.
- [Marin Social API](https://support.marinsoftware.com/en_US/platform-intro-metrics/marin-social-api-documentation): documented as existing, but its only reference link points at developers.marinsoftware.com, which no longer serves documentation. No base URL is recoverable.

## Contract

- Endpoints: `/campaigns`, `/groups`, `/keywords`, `/ads`, `/strategies`
- Request form: `POST {base}/{version}/bulk/{endpoint}?clientId=&customerId=&userId=&userCustomerId=`
- Body: a single `data` array of rows keyed by bulk-sheet column headers, e.g. `{"data":[{"Account":"Test","Campaign":"Search & Content","Daily Budget":2}]}`
- [Field reference (the de-facto schema)](https://support.marinsoftware.com/en_US/bulk-actions/bulk-upload-requirements)
- Errors: only HTTP 200 and 500 are documented; no error body schema
- No OpenAPI, AsyncAPI, GraphQL SDL, JSON Schema or Postman collection is published anywhere
